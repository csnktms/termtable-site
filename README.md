# Termtable site

Marketing and support page for **Termtable**, an iOS timetable app built for university schedules that change every term — not every week.

**Live:** [csnktms.github.io/termtable-site](https://csnktms.github.io/termtable-site/)

## About

A single self-contained `index.html` — inline CSS, no build step, no dependencies, no analytics or external requests. Served via GitHub Pages from the root of `main`.

The page doubles as the App Store support URL ([`/#support`](https://csnktms.github.io/termtable-site/#support)) and privacy statement ([`/#privacy`](https://csnktms.github.io/termtable-site/#privacy)).

## Development

Open `index.html` in a browser. That's it.
